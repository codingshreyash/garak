garak.probes.audio_reliability
================================

.. automodule:: garak.probes.audio_reliability
   :members:
   :undoc-members:
   :show-inheritance:

``Semantic`` renders a small set of benign requests through the PETTS helper
and checks whether the audio-capable target returns the expected meaning. This
provides a channel check before interpreting results from adversarial audio
probes. Set ``source_data_path`` to use a replacement JSON case file.
